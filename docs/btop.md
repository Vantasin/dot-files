# Btop Notes

## Location
- Stowed from `btop/dot-config/btop/` to `~/.config/btop/`.

## Content
- `btop.conf` and related user-space settings.

## Usage
- Preferred: `make stow`.
- One-package raw Stow: `stow --dotfiles --ignore='(\.DS_Store|README\.md)$' --target="$HOME" btop`.
- Restart btop to pick up changes.
